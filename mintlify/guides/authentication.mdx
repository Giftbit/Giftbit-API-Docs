---
title: "Authentication"
description: "Authenticate with the Giftbit API using a bearer token in the Authorization header."
---

Authenticate with the Giftbit API by sending your API token prefixed by the word `Bearer` (case sensitive) and a space in the `Authorization` HTTP header.

```http
Authorization: Bearer YOUR_API_KEY
```

Generate an API token from the **Account → API keys** section of your Giftbit account. You have a separate token for each environment — see [Environments and URLs](/guides/environments).

<Tip>
  The [`/ping`](/api-reference/ping/ping) endpoint is a convenient way to test your authentication.
</Tip>
