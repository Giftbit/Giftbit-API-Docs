---
title: "Going live"
description: "Move your integration from the Testbed to Production and share feedback on the API documentation."
---

When your integration is ready to launch, sign up at [giftbit.com](https://www.giftbit.com) and contact [sales@giftbit.com](mailto:sales@giftbit.com) to signal production readiness. The Giftbit team will enable permissions to generate an API token in your production account.

<Info>
  Review the [environment differences](/guides/environments#environment-differences) before you go live, especially the change in reward-brand availability and the switch from test credit cards to real payments.
</Info>

## Providing feedback on the API documentation

The Giftbit team makes heavy use of external APIs ourselves, and we know how frustrating it can be when documentation is unclear or doesn't match the actual API behaviour. If you find any such problems with ours, don't hesitate to let us know via [testbed@giftbit.com](mailto:testbed@giftbit.com).
