title: "Introduction"
description: "Automatically order digital rewards and deliver them to your recipients with the Giftbit REST API."
---

Giftbit's REST API allows you to automatically order rewards and send them to your recipients. Delivery can be handled either by links that are intergrated into another system’s workflow or by emails that are sent through the Giftbit system.

This documentation includes a definitive list of endpoints under the [API reference](/api-reference/ping/ping), an [error code reference](/guides/errors), code examples, and a [guide to getting started](/guides/getting-started).

<Steps>
  <Step title="Sign up for the Testbed">
    Sign up at [testbedapp.giftbit.com](https://testbedapp.giftbit.com/register/index) and visit **Account → API keys** to generate an API token for the Testbed environment.
  </Step>
  <Step title="Explore with a virtual balance">
    Your Testbed account provides a large virtual account balance, so you can place orders and redeem test cards to observe the recipient experience.
  </Step>
  <Step title="Go live">
    When your integration is ready to launch, sign up at [giftbit.com](https://www.giftbit.com) and contact [sales@giftbit.com](mailto:sales@giftbit.com) to signal production readiness. See [Going live](/guides/going-live) for details.
  </Step>
</Steps>

<Info>
  Giftbit has dedicated technical and business resources to help you choose the right implementation path for your integration. Email [sales@giftbit.com](mailto:sales@giftbit.com) to get assistance with your project.
</Info>
